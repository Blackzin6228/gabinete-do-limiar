# Gabinete do Limiar

Mod de horror paranormal do CONGUITOS SMP (NeoForge 1.21.1, Java 21).

Os jogadores são agentes do Gabinete do Limiar: atenderam um chamado na mata e atravessaram para outro lugar.

- Mod id: `odteste` (fica igual ao mod antigo, para o mundo do servidor continuar funcionando).
- Regras para quem mexe: `CLAUDE.md`. Estado atual: `docs/passagem-de-turno.md`.
